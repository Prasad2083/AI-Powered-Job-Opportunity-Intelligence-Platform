## 🔍 USEFUL COMMANDS

```bash
# Check if Docker is running
docker ps

# View all containers
docker-compose ps

# View backend logs
docker-compose logs postgres

# Reset database
docker-compose down -v
docker-compose up -d postgres redis

# Check if port is in use
lsof -i :8080
lsof -i :3000

# Kill process on port
kill -9 <PID>

# Test backend health
curl http://localhost:8080/api/health

# Test frontend
curl http://localhost:3000
```

## 🆘 QUICK FIXES

| Problem | Solution |
|---------|----------|
| `command not found: docker` | Install Docker Desktop |
| `command not found: java` | `brew install openjdk@21` |
| `Port 8080 in use` | `kill -9 $(lsof -t -i:8080)` |
| `Port 3000 in use` | `kill -9 $(lsof -t -i:3000)` |
| `npm install hangs` | `npm cache clean --force` |
| `Docker daemon not running` | Open Docker Desktop app |
| `Can't connect to database` | `docker-compose up -d postgres` |
| `Build fails` | `mvn clean install -U` |
