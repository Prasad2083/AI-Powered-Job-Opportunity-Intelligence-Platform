# JobPulse LinkedIn demo kit

[Download the complete demo kit](JobPulse-short-demo-kit.zip).

The ZIP contains a 40-second, 1080p MP4, an HD cover image, a suggested LinkedIn caption and production notes. The recording shows the redesigned application with clearly labelled demonstration data and a simulated AI response. No real applications were submitted.

## Download from GitHub

Open `JobPulse-short-demo-kit.zip` on the feature branch, then select **Download raw file**. If GitHub requires authentication, sign in with the account that has access to this repository.

## Retrieve on your Mac

From the repository directory while on `feature/production-workflow-20261027`:

```bash
git pull --ff-only
open docs/demo/JobPulse-short-demo-kit.zip
```

macOS Archive Utility extracts the kit. Upload the MP4 directly to LinkedIn and use the supplied PNG as the thumbnail where supported. Review and personalize the caption before publishing.
